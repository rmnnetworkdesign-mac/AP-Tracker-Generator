Export & SharePoint

  1. Download the populated workbook — Site Data, AP Tracker and Net Equip Tracker are all filled in.
  2. Open it in Excel. The AP Name, Description and formatted MAC columns recalculate on open.
  3. Upload to the SharePoint project folder as normal.
  4. The Site Data tab still needs SSID keys and PM / designer names if your process requires them.
The workbook pre-fills Site Data (site, CLLI, vendor, vertical, vSZ zone, device counts), AP Tracker (serial, raw MAC in col K, model, AP number, building, floor, installed area) and Net Equip Tracker (type, model, serial, raw MAC, building, floor, device number, location).
